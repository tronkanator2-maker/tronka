# Мир моделей — Telegram Bot

Первый технический MVP по ТЗ. Функции: бот, анкеты, фото, публикация заявок, фильтры, прямые отклики, жалобы и PostgreSQL.

Railway env: BOT_TOKEN, WEBHOOK_SECRET, PUBLIC_URL, DATABASE_URL, REGISTRATION_ENABLED=false, ADMIN_IDS.

**Нельзя включать регистрацию без согласованных юридических документов.** Не реализованы: парсинг всех Telegram-источников, ЕСИА, эквайринг, полноценная админка, NLU, несовершеннолетние, подписки. Для готовности к запуску требуется тестирование пользовательских сценариев.
